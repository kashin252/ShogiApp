# 修正完了報告 (Version 74)

将棋エンジンの連携不具合、持ち駒のバグ、およびビルドエラーの全てを修正し、最新のAAB（Version 74）を作成しました。

## 実装した修正内容

### 1. 将棋エンジン (Rust) の連携
- **JNIシグネチャの修正**: Rust側のNative関数で不要な引数を削除し、Androidからの呼び出しでクラッシュする問題を解消しました。
- **結果解析ロジックの修正**: Rustエンジンが「JSON」ではなく「パイプ区切り形式(`move|score|depth|nodes`)」を返している実態に合わせ、TypeScript側のパースロジックを修正しました。

### 2. 持ち駒バグの修正
- **配列サイズの拡大**: `hand` 配列が `Int8Array(7)`（インデックス0-6）となっており、飛車（HI = 7）などのインデックスで範囲外アクセス（Undefined）が発生していたのを `Int8Array(17)` に拡大しました。これにより持ち駒に異常な駒（飛車など）が表示される問題を解決しました。
- **初期化漏れの修正**: `reset()` メソッドで持ち駒（`hand`）と手番（`turn`）がリセットされていなかったため、対局やり直し時に前の状態が残る問題を修正しました。

### 3. ビルドと新アーキテクチャ対応
- **New Architecture (Fabric) の有効化**: 他のライブラリ（`react-native-iap` / Nitro）との互換性を保つため、`newArchEnabled=true` を維持した状態で、コンパイルエラーを解消しました。
